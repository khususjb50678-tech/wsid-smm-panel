LANGKAH DEPLOY WSID SMM PANEL — FINAL

1. GITHUB
- Upload semua file ZIP ini langsung ke ROOT repository.
- GitHub Pages: Settings > Pages > Deploy from branch > main > /(root).

2. SUPABASE
- SQL Editor > New query.
- Jalankan RUN_ALL.sql sekali.

3. AUTH
- Authentication > URL Configuration.
- Site URL = URL GitHub Pages.
- Redirect URL = URL GitHub Pages/**
- Jika ingin register langsung aktif, matikan Confirm Email.

4. ADMIN
- Daftar akun melalui register.html.
- Jadikan akun admin melalui SQL:
  update public.profiles set role='admin' where email='EMAIL_KAMU';
- Buka admin.html.

5. SETTINGS
Admin > Settings:
- Nama Panel
- Nama Owner
- Nomor DANA
- Nama DANA
- URL QRIS
- WhatsApp
- Telegram
- Instagram
- Telegram Chat ID

6. KONEKSI LAYANAN
Admin > Koneksi:
- Isi ID koneksi dan kunci koneksi.
- Tes Koneksi.
- Sync Layanan.
- Atur markup persen atau tetap.

7. DEPOSIT
User:
- Deposit
- Ketik nominal sendiri
- Minimal Rp2.000
- Transfer DANA
- Upload bukti
- Kirim Pengajuan Deposit
- Tunggu ACC Admin

Admin:
- Deposit
- Lihat bukti
- ACC atau Tolak
- ACC menambah saldo user satu kali.

8. TELEGRAM NOTIFIKASI
- Buat bot Telegram dengan BotFather.
- Deploy Edge Function `telegram-deposit-notify` memakai file `SQL Telegram notification`.
- Supabase Edge Function Secrets:
  TELEGRAM_BOT_TOKEN = token bot Telegram.
- Isi Telegram Chat ID admin di Admin > Settings.
- Bot akan mengirim notifikasi setiap ada deposit baru.

9. CARA MENDAPATKAN CHAT ID
- Chat bot yang dibuat sampai bot menerima pesan.
- Ambil Chat ID dari metode bot Telegram yang kamu gunakan.
- Masukkan angka Chat ID tersebut di Admin > Settings.

10. KEAMANAN
- Jangan masukkan TELEGRAM_BOT_TOKEN ke config.js.
- Jangan kirim token bot ke chat.
- Supabase URL dan anon/publishable key di config.js boleh berada di frontend.

11. YANG BELUM DIPAKAI
- Docs API publik.
- API ID/API Key untuk user.
