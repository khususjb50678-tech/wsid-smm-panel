CARA PASANG (urut):

A. Supabase SQL Editor
1. Buka Supabase project.
2. SQL Editor > New query.
3. Buka file schema.sql dari paket ini.
4. Copy semua isinya.
5. Paste ke SQL Editor.
6. Run.

B. Deploy Edge Functions
Buat/deploy 3 function:
- provider-fayupedia       <- edge_provider_fayupedia.ts
- provider-order           <- edge_provider_order.ts
- wsid-api                 <- edge_public_api.ts

Nama function harus sama persis.

C. GitHub Pages
Upload/replace semua file paket ini ke ROOT repository.
Jangan masukkan ke folder baru.

D. Setelah login sebagai admin
1. Buka Admin > Provider.
2. Isi API ID provider.
3. Isi API Key provider.
4. Cek Base URL.
5. Simpan API Provider.
6. Klik Test Connection.
7. Jika berhasil, klik Sync Services.

E. Settings
Buka Admin > Settings lalu isi semua data panel/DANA/kontak.
Setelah disimpan, data akan dipakai website. Tidak perlu edit config.js lagi.

F. API user
1. Admin > Users.
2. Pilih user.
3. Klik Buat API.
4. Simpan API ID dan API Key yang muncul.
5. Jika Reset API, key lama langsung tidak berlaku.
